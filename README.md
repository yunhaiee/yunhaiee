# Yunha Lee

Stanford '30. I build AI systems that have to work outside the demo: on a phone in airplane mode, in an ambulance, inside a traffic simulator.

## Projects

- **[Remy](https://github.com/yunhaiee/Remy)**: a hands-free cooking coach that runs fully on the phone. Gemma 4 on LiteRT-LM (iPhone GPU, Pixel Tensor NPU) plans and talks; a model-free hand-tracking loop warns before you touch a hot pan. Google Gemma Hardware Hackathon, AGI House, Oct 2026.
- **[nanobite](https://github.com/jjang-07/nanobite)**: an MCP tool that lets one company's coding agent ask another's, with redaction rules and human approval in between. **Best Agent Communication Setup**, YC *Make Something Agents Want* hackathon, Oct 2026.
- **[Kardza](https://github.com/yunhaiee/kardza-hackathon)**: a trading-card marketplace that adapts to each user's age and country through real k-ID sessions, with voice-note safety screening and parent-approved checkout. Build for Everyone (Google x k-ID), Oct 2026.
- **[ambulance](https://github.com/yunhaiee/ambulance)**: a multi-agent ER dispatch system. The ambulance's agent triages the patient and asks hospital agents in parallel over A2A, finding an ER in about 50 seconds.
- **[AVC](https://github.com/yunhaiee/AVC)**: car-following trajectory prediction for the IEEE ITSS Autonomous Vehicle Challenge, run as pre-registered experiments with explicit go/no-go calls. Aug 2026.
- **[TUPA lab website](https://github.com/yunhaiee/TUPA)**: Next.js and Notion CMS site for a KAIST mobility lab, edited by the professor without code. [tupa-two.vercel.app](https://tupa-two.vercel.app)
- **[dochak.com](https://github.com/dochak-Inc/dochakWebsite)**: website for Dochak, a traffic-simulation company.
